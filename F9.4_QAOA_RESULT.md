# F9.4 QAOA Result

## Implementation

F9.4 reuses the repository's bounded QAOA circuit builder, local
statevector simulator, seeded measurement sampler, and deterministic bounded
parameter search. The new task-hour adapter accepts the existing F9.3
`AssignmentQuboIsing` plus its F9.2 matrix, revalidates that the formulation
matches the matrix, and sends the existing Ising coefficients to QAOA.

The QAOA engine's established measured-bit convention uses `s=2x-1`; F9.3's
source Ising uses `z=1-2x`. The adapter applies `z=-s` by negating only the
linear fields at the simulator boundary. This preserves the source Ising
energy and leaves the F9.3 QUBO/Ising formulation unchanged. The raw measured
bitstring decodes directly to the F9.2 `x[t,h]` variables.

The circuit uses `H_C = Σ hᵢZᵢ + Σ JᵢⱼZᵢZⱼ`, an initial `|+⟩ⁿ` state, and
`p` alternating cost unitaries `exp(-iγₖH_C)` and mixer unitaries
`exp(-iβₖΣXᵢ)`. The existing statevector simulator returns a normalized
state and seeded shot counts; measured outcomes are candidates, not guaranteed
global optima.

Configuration supports depth `p`, explicit gamma/beta tuples, bounded
parameter-search iterations, shots, and a deterministic random seed. The
hard local caps are eight variables/qubits, depth 3, 25 parameter trials, and
10,000 shots. Larger problems return `TOO_LARGE`; configurations above those
limits return `NOT_SUPPORTED`, without simulation. The candidate is never
repaired. The result reports its raw assignment, feasibility and violations, QUBO and Ising
energies, original F9.2 matrix objective, classical optimum, exact QUBO
optimum for these small supported sizes, observed counts/probabilities, and
an approximation ratio only when meaningful.

## Deterministic test result

For the explicitly synthetic 2-task/2-hour matrix with scores
`[[90, 10], [20, 80]]`, depth 1, gamma `0.11`, beta `0.27`, 512 shots, and
seed 41:

- Classical optimum: **170**.
- Exact QUBO optimum: **energy -170**, corresponding objective **170**.
- Measured QAOA candidate: assignment `task-a→9`, `task-b→10`.
- Candidate objective: **170**; QUBO and Ising energy: **-170**.
- Feasibility: **true**; approximation ratio: **1.0**.

This is one deterministic test outcome, not a guarantee for other matrices
or parameters and not production evidence. Additional tests include a seeded
infeasible raw bitstring, which remains explicitly infeasible and unrepaired.

  candidate, not a recommendation.

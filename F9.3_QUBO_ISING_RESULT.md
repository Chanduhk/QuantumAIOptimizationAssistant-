# F9.3 QUBO / Ising Result

## Formulation

For the validated F9.2 score matrix `P[t,h]`, binary variables are indexed
deterministically by task-ID type/value and sorted candidate hour:
`x[t,h] ∈ {0,1}`. Their stable IDs are `x_<task-index>_<hour-index>`.
The source objective remains `maximize Σ P[t,h] x[t,h]`; the QUBO energy
minimizes its negative.

The encoded energy is:

```text
E(x) = -Σ[t,h] P[t,h]x[t,h]
       + M Σ[t] (Σ[h]x[t,h] - 1)²
       + M Σ[h] Σ[t<u] x[t,h]x[u,h]
```

The first penalty enforces exactly one hour per task. The second charges each
pair of tasks sharing an hour and therefore enforces at most one task per
hour. Using `x²=x`, the constant offset is `M × task_count`; each variable's
linear coefficient is `-P[t,h] - M`; same-task/different-hour couplings are
`2M`; same-hour/different-task couplings are `M`.

## Penalty guarantee

Validated F9.2 scores are finite and in `[0,100]`. Let
`S = Σ[t,h] P[t,h]`, an upper bound on the score reward of every binary
assignment. The builder derives `M = S + 1`; this is not an application
weight. Every infeasible binary assignment has an integer violation count of
at least one, so its energy is at least `-S + M = 1`. Every feasible
assignment has energy `-objective ≤ 0`. Thus every global QUBO minimum is
feasible and the feasible minimum maximizes the unchanged F9.2 objective.

## Ising mapping

The F9.3 conversion uses `x=(1-z)/2`, `z∈{-1,+1}`. For QUBO coefficients
`c + Σ aᵢxᵢ + Σ bᵢⱼxᵢxⱼ`, the Ising values are:

```text
constant = c + Σ aᵢ/2 + Σ bᵢⱼ/4
hᵢ       = -aᵢ/2 - Σⱼ bᵢⱼ/4
Jᵢⱼ     = bᵢⱼ/4
```

Exhaustive tests check exact energy correspondence for every state in the
small test problems. QUBO and Ising models use the repository's immutable
problem contracts and retain task/hour mapping, constraints, score/model
provenance, mode, and penalty derivation.

## Equivalence evidence and production gate

Exhaustive test-only cases cover 1 task, 2×2, 3×3, and 2×3 task/hour sizes.
They compare every binary state's QUBO/Ising energy and feasibility, then
compare the feasible optimum and objective with the deterministic F9.2
classical optimizer. TEST/SYNTHETIC matrices require explicit test mode and
are labeled as such. They cannot establish production readiness.

The production path formulates QUBO/Ising only after the existing classical
optimizer accepts a complete, provenance-validated, non-trivial production
matrix. No eligible production matrix is currently established, so
production quantum readiness remains **NOT_READY**. The orchestrator does
not invoke a quantum suitability checker or execution from this stage.
